    Come leggere l'esito. Se una o più righe sono contrassegnate con ✘, quel file non è stato caricato oppure è finito nella cartella sbagliata. La struttura corretta sul server è: le pagine .html nella radice del sito, il foglio di stile e il motore di ricerca dentro la cartella assets/, tutti i file dei dati dentro la cartella data/. I nomi delle cartelle e dei file vanno rispettati esattamente, minuscole comprese: molti server distinguono Data da data.
