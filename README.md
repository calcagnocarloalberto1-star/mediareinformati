# mediareinformati.it

Piattaforma di consultazione e ricerca sulla mediazione: storia, pratica, diritto,
sistemi nazionali, link istituzionali mondiali, dati e statistiche, articoli d'autore
e giurisprudenza.

Sito statico puro (HTML + CSS + JavaScript, nessuna dipendenza): le pagine `.html`
stanno nella radice, lo stile e il motore di ricerca in `assets/`, la banca dati del
sito in `data/` (un file JS per motore). La pagina `verifica.html` controlla che
tutti i file siano al loro posto sul server.

La manutenzione è documentata in `COME_AGGIORNARE.md`; gli strumenti redazionali
(script di rigenerazione dati, massimario, vaglio di pertinenza) sono in `strumenti/`.
